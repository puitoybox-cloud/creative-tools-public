# creative-tools-public

iPadで開くための創作用ツール公開版です。HTML、CSS、JavaScriptだけで動く、シンプルな設定管理Webアプリです。

> **公開用の注意**  
> このリポジトリには、作品本編の設定や秘密情報を入れないでください。アプリに最初から入っている内容も、公開してよい架空のサンプルデータだけです。

## できること

- キャラクター設定を登録・表示できます。
- 話数メモを登録・表示できます。
- 画像生成プロンプトを登録・表示できます。
- 入力内容はブラウザ内の `localStorage` に保存されます。
- iPadのSafariで見やすいように、文字とボタンを大きめにしています。

## ファイル構成

```text
creative-tools-public/
├── index.html   # 画面の構造
├── styles.css   # 見た目
├── app.js       # 登録・表示・保存の動き
└── README.md    # この説明書
```

## 初心者向け：使い方

1. `index.html` をブラウザで開きます。
2. 「キャラクター」「話数メモ」「画像プロンプト」のタブを選びます。
3. 入力欄に内容を書きます。
4. 「保存する」ボタンを押します。
5. 右側または下側の「登録済み」にカードとして表示されます。

### 削除したいとき

- 1件だけ消したい場合は、カード内の「削除」を押します。
- 今開いているタブを全部消したい場合は、「このタブを全削除」を押します。
- 最初のサンプルに戻したい場合は、「サンプルに戻す」を押します。

## 保存について

入力内容は、使っているブラウザの中だけに保存されます。サーバーには送信されません。

注意点：

- iPadのSafariでWebサイトデータを削除すると、保存内容も消えることがあります。
- 別の端末や別のブラウザには自動共有されません。
- GitHub Pagesで公開しても、あなたのブラウザに保存した内容が他の人へ公開されるわけではありません。

## GitHub Pagesで公開する手順

1. GitHubでこのリポジトリを開きます。
2. 上部メニューの **Settings** を開きます。
3. 左メニューの **Pages** を開きます。
4. **Build and deployment** の **Source** を **Deploy from a branch** にします。
5. **Branch** で公開したいブランチを選びます。通常は `main` です。
6. フォルダは `/(root)` を選びます。
7. **Save** を押します。
8. 数十秒〜数分待つと、Pages画面に公開URLが表示されます。
9. iPadのSafariでそのURLを開きます。

## 公開前チェック

公開前に、次を確認してください。

- 本編設定、未公開設定、秘密の名前、プロットの核心を書いていない。
- サンプルとして公開してよい内容だけになっている。
- `app.js` の `sampleData` に実在の本編情報を入れていない。

## ローカルで確認する方法

いちばん簡単な方法は、`index.html` をダブルクリックしてブラウザで開くことです。

コマンドで確認したい場合は、リポジトリのフォルダで次を実行します。

```bash
python3 -m http.server 8000
```

そのあと、ブラウザで `http://localhost:8000` を開きます。
